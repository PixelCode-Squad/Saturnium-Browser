# Política de Segurança — SaturniumBrowser

## Versões com suporte

O SaturniumBrowser está em desenvolvimento contínuo. A versão mais recente publicada no repositório oficial é a referência principal para correções. Versões antigas podem não receber atualizações.

## Como relatar uma vulnerabilidade

Não publique senhas, chaves de API, dados pessoais, provas de conceito exploráveis ou detalhes que coloquem outros usuários em risco em uma issue pública.

Se o recurso **Private vulnerability reporting** estiver habilitado no GitHub para este repositório, utilize-o para enviar o relato de forma privada. Caso não esteja disponível, abra uma issue sem detalhes técnicos sensíveis solicitando um canal privado de contato.

Inclua, quando possível, a versão afetada, o sistema operacional, o impacto observado e passos seguros para reproduzir o problema.

## Escopo

Relatos sobre o código do SaturniumBrowser, suas extensões oficiais, scripts de build e workflows são relevantes. Vulnerabilidades em sites, serviços externos, Electron ou dependências devem ser encaminhadas também aos respectivos mantenedores quando apropriado.

## Processo

O mantenedor analisará o relato, tentará confirmar o problema, avaliará o impacto e preparará uma correção. A divulgação pública deve ocorrer após a disponibilização de uma correção ou após coordenação com os envolvidos, quando possível.
